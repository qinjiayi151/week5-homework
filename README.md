 ## 人机协同反思
 ### 1. 意图清晰度反思
 在本次实验里，我第一次让AI写双摆代码的时候，生成结果不符合预期，直接把原来的单摆代码覆盖掉了。回看当时的提示词，缺少约束条件，没有告诉AI要保留已经写好的单摆代码。后面我补充了要求，让AI新建一个独立HTML文件来写双摆，不去改动单摆代码，这样两个模拟器就都保留下来了。
 ### 2. 闭环控制反思
 当代码报错、动画无法正常显示时，我先打开网页查看页面状态，检查文件名和后缀有没有写错，一点点定位问题。AI给出的修复方案我基本看懂了，它是把单摆和双摆的变量、画布分开，不让两套模拟互相干扰，解决画面被覆盖、模拟器消失的问题。
 ### 3. 主体地位确认
 作为人在回路之上的设计者：
 我做的核心决策：确定项目要同时实现单摆、双摆两套模拟器，决定分成两个独立网页存放代码，规划使用Git和GitHub管理项目文件，整理README文档。
 AI完成的重复工作：编写单摆、双摆的物理仿真代码，写动画绘图逻辑，辅助修改代码bug，帮忙撰写项目介绍文字。
